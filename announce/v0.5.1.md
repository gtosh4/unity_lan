**UnityLAN v0.5.1** — a reliable Windows auto-update and one window per engine.

**Fixed**
- On Windows, an auto-update no longer risks leaving the engine stopped with the mesh down until you restart it by hand. The service used to hand its own restart to a helper it launched only *after* reporting stopped — and if Windows ended the process in that instant, the restart never happened. The engine now launches the restart first and registers a Service recovery action as a backstop, so it comes back on the new version even if the hand-off is missed. Leftover `unitylan-gui.old.exe` files are also cleaned up on the next start.

**Changed**
- Launching the GUI a second time (tray, shortcut, or command line) no longer opens a duplicate — it surfaces the window you already have, restoring it from the tray or taskbar and taking focus. On Wayland, where the compositor blocks one app from raising over another, the existing window flags its taskbar entry for attention instead (click it to raise). Each engine you point a GUI at still gets its own single window.
